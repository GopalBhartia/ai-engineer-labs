# AI Engineering Notes

AI engineering is the practice of building applications that use machine learning models, large language models, APIs, data pipelines, and production software engineering.

An AI engineer needs to understand both model behavior and software systems. This includes Python, APIs, testing, deployment, observability, prompt engineering, retrieval, and evaluation.

A good AI application should be useful, reliable, testable, and maintainable. The goal is not only to call an LLM API, but to build a complete system around it.
